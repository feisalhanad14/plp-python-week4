# Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python assignment for practicing decision-making, conditions, validation, and nested conditionals.

## Files

- `grade_classifier.py` - Classifies a score from 0 to 100 into grades A, B, C, D, or F and validates the input.
- `eligibility_checker.py` - Checks whether a person is eligible to join a coding club based on age and parental consent.
- `atm_menu.py` - Simulates an ATM PIN check and withdrawal using nested decisions.
- `screenshots/` - Contains screenshots showing the programs running with different inputs.

## Why is `elif` better than several separate `if` statements?

`elif` is better when only one condition should be selected from several possible choices. Once Python finds a true `if` or `elif` condition, it skips the remaining conditions. This makes the code clearer and prevents multiple results from being selected for the same input.
